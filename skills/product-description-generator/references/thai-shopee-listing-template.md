# Thai Shopee listing template

Use this template when the target marketplace is Shopee Thailand. The customer-facing copy is Thai; the Chinese review translation is a separate section and is never mixed into the listing.

## 1. Product truth table

Record each fact as one of:

- `confirmed`: directly stated by the user, specification, or product reference;
- `unknown`: not established and must not be presented as fact;
- `forbidden inference`: a tempting claim that the evidence does not support.

The newest explicit user confirmation overrides an older project brief. A restriction for one product must not become a universal restriction for another product.

## 2. Customer-facing output

Deliver all of the following in Thai:

1. One search-readable title within the current platform input limit.
2. Five concise highlights, one main fact per line.
3. A complete detail page with a short opening benefit, feature explanations, practical use cases, and a clear closing prompt.
4. A specification block with only confirmed material, dimensions, variants, components, and usage information.
5. Color or variant information and purchase notes.

Put the primary product keyword near the beginning, then add confirmed material, structure, measurable parameters, and use context in natural Thai order. Avoid keyword stuffing, invented brands, model numbers, certifications, exact usable capacity, or performance grades.

## 3. Capacity and performance discipline

External dimensions can support a size description. They do not automatically prove an exact usable litre capacity because walls, seams, compartments, closures, and the shape of stored objects reduce usable space. If a geometric estimate is useful, label it as an upper-bound estimate and keep it separate from tested capacity.

Use performance words such as waterproof, leakproof, insulated, antibacterial, or impact-resistant only when the current product evidence supports the exact scope. Do not silently broaden a confirmed claim into “100%”, “all-day”, “tested”, or universal superiority.

## 4. Review output

After the Thai copy, provide a Chinese translation for review, the title character count, and a claim audit listing each measurable or performance statement and its evidence source. Check Thai spelling, spacing, numerals, units, and natural marketplace phrasing before calling the listing complete.
